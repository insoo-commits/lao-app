아이폰·아이패드

꼭 Safari로 열어 주세요
1
Safari에서 앱 주소를 열어요.
2
아래(아이패드는 위)의 공유 버튼을 눌러요.
3
목록을 내려서 ⊞ 홈 화면에 추가를 눌러요.
4
오른쪽 위 추가를 누르면 끝!
홈 화면에 LAO Lang 아이콘이 생겨요.

안드로이드폰

Chrome(크롬)으로 열어 주세요
1
Chrome에서 앱 주소를 열어요.
2
오른쪽 위 ⋮ 메뉴를 눌러요.
3
홈 화면에 추가 또는 앱 설치를 눌러요.
4
설치를 누르면 끝!
삼성 인터넷은 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면

PC (윈도우·맥)

Chrome 또는 Edge로 열어 주세요
1
Chrome이나 Edge에서 앱 주소를 열어요.
2
주소창 오른쪽 끝의 설치 아이콘을 눌러요.
3
아이콘이 안 보이면 ⋮ 또는 … 메뉴 → 앱 → 설치를 찾아요.
4
설치를 누르면 끝!
바탕화면·시작 메뉴에서 앱처럼 열려요.
